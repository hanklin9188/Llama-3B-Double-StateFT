# Attribution and Provenance Notice

The repository uses the Apache License 2.0 text currently stored in [`LICENSE`](LICENSE). That file contains the notice:

```text
Copyright 2025 Zhang Chi
```

This repository-hardening change intentionally preserves that notice. It does not infer that all current files have the same origin, and it does not replace an upstream attribution without evidence.

Before redistributing, relicensing, or making an ownership claim, complete a provenance audit that records:

- the upstream project and repository URL, if any;
- the exact upstream commit or release;
- files derived from upstream material;
- files independently authored or substantially modified here;
- required notices under the upstream license;
- modification dates and responsible authors.

Git history and pull-request descriptions should document new modifications. Until the audit is complete, the safest interpretation is that the existing Apache-2.0 attribution must be retained.
